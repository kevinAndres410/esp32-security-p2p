# esp32-security-p2p
Aplicativo web de seguridad ligera y autónoma basada en cifrado dinámico para redes domóticas inalámbricas P2P con ESP32.

La preparación de kits nuevos (un Gateway y tres nodos), el reclamo de cada kit por cuenta y el flujo de aprobación están documentados en [KITS_ESP32.md](KITS_ESP32.md).

El panel Administrador Maestro, sus rutas, controles de seguridad, copias de
seguridad y el procedimiento para habilitar la primera cuenta administradora se
documentan en [docs/MASTER_ADMIN_ARCHITECTURE.md](docs/MASTER_ADMIN_ARCHITECTURE.md).

La preparación individual de placas y la incorporación, sustitución o retirada
desde la web se explican en [docs/dynamic-kit.md](docs/dynamic-kit.md).
